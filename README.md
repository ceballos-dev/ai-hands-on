# AI Hands-On

Practical log of how I use AI in real product and technical delivery work: connecting LLMs to tools (MCP), writing reusable AI instructions for tickets and triage, AI on a real codebase, and an end-to-end client delivery case.

Each week documents **what I built, what failed and how I fixed it**. Every AI output is verified against the real system (API responses, the target tool's UI, the source spec).
